# YURICH screenshots

The root README uses these stable image paths:

- `search.png` — project search and grouped results
- `editor.png` — quick editor with an opened file
- `settings.png` — settings, recent folders, and favorites

Replace the files in this directory when the interface changes; the links in
the root README do not need to be edited. PNG is recommended for crisp UI text.
Before publishing, check screenshots for private paths, tokens, email addresses,
or other sensitive information.
